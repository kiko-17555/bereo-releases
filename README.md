# Bereo pour Windows

Ce dépôt ne contient que les **installeurs** de l'application de bureau Bereo, l'application d'étude biblique.
Le code de Bereo n'est pas ici.

**Télécharger :** https://bereo-beta.vercel.app/telecharger/

Chaque version publiée dans [Releases](https://github.com/kiko-17555/bereo-releases/releases) est récupérée
automatiquement par les applications déjà installées, à leur ouverture suivante.

Pendant la bêta, l'installeur n'est pas signé : Windows affiche « Windows a protégé votre ordinateur ».
Cliquez sur **Informations complémentaires**, puis **Exécuter quand même**.
